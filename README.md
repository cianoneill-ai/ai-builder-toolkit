Practical checklists, cheat sheets and prompts from building and running real AI systems as a non-engineer: an autonomous agent fleet, a local-first smart home system, and research agents.

Written by [Cian O'Neill](https://cianoneill.ai). Every item here came out of something I built, broke, or audited.

## Using the skills

Each folder in `skills/` holds one `SKILL.md`. It follows the open [Agent Skills](https://agentskills.io) format, so it works in Claude, ChatGPT/Codex, Gemini CLI and Cursor. In Claude, zip the folder and upload it under Settings > Capabilities > Skills. In a coding agent, drop the folder into its skills directory. Pair them with the Shopify connector.
