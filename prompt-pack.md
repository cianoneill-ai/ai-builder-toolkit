# Prompts that force real answers

Paste these at the start of a conversation, or save them as custom instructions.

## Sparring partner

```
Challenge this as a sparring partner. Don't default to agreeing with me.
Give me the three strongest arguments against it before anything positive.
```

## Kill conditions

```
What would have to be true for this to be wrong?
List the assumptions, and tell me which one is weakest.
```

## No hedging

```
Give me a high-conviction answer with specific detail.
No "it depends" and no "may be worth considering".
If you're uncertain, say how uncertain and why, once.
```

## Find the gaps

```
Here is my plan. Don't improve it.
Tell me what's missing, what I haven't priced in, and what will break first.
```

## Deeper pass

```
That came back quickly. Do a deeper pass: no stones unturned,
trace it end to end, and tell me what the first pass missed.
```

## Scoped constraint

```
Constraint: [rule]. Scope: [exactly what it applies to].
It does not apply to: [everything else].
```

## Structured research (the Gordon template)

```
Write this as: thesis, supporting evidence, the strongest counter-argument,
and the conditions that would prove the thesis wrong.
Every section must be filled. If the counter-argument is thin, say so.
```
